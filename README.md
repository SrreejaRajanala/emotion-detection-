# Emotion Detection App

## 📌 Project Description

This project detects human emotions using deep learning models like ResNet, GoogleNet, and Swin Transformer.

## 🚀 Features

* Real-time emotion detection (camera)
* Image-based prediction
* Multiple trained models

## 📁 Project Structure

* app.py → Main Flask application
* templates/ → HTML pages
* static/ → CSS, JS

## ⚙️ Setup Instructions

1. Clone the repository:
   git clone https://github.com/harshi414/emotion-detection.git

2. Install dependencies:
   pip install -r requirements.txt

3. Download model files from Google Drive:
   https://drive.google.com/drive/u/0/folders/1nAIbz9IvWGIoDhLHc6r5Z1Rw3DzrEWXs

4. Place the downloaded files inside:
   models/

5. Run the app:
   python app.py

## ⚠️ Note

Model files (.pth) are not included in this repository due to GitHub file size limitations.
